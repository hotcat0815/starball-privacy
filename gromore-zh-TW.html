一、運營主體與適用範圍

《畫素彈球：星島奇旅》（以下簡稱“本遊戲”）由北京悠遊創想科技有限公司（以下簡稱“我們”）運營。本政策適用於本遊戲 Android 應用及本隱私政策展示頁面。當前 Android 包名為com.yycx.starball。

請在使用前閱讀本政策，尤其是第三方廣告服務和未成年人保護部分。第三方平臺、外部網頁及您另行安裝的應用，其獨立提供的服務適用各自的隱私政策。本政策不能替代第三方政策，也不意味著我們可以免除自身的個人資訊保護責任。

二、我們如何處理資訊

1. 本地遊戲資料

為儲存您的遊玩體驗，遊戲在應用私有儲存空間儲存關卡解鎖、通關記錄、分數、星級、挑戰記錄、外觀選擇、引導完成狀態、聲音及動效設定、隱私政策授權版本等資料。當前版本沒有自行搭建賬號或雲存檔伺服器；您同意隱私政策後，會透過友盟上報下文說明的主線關卡事件，不上傳完整存檔。

2. 廣告服務

本版本透過 GroMore 聚合穿山甲和騰訊廣告，提供橫幅、自願觀看的激勵影片及關卡間插屏。騰訊廣告 SDK 在使用者同意後按排程參與廣告載入與展示，處理 OAID、裝置與系統資訊、應用及網路資訊、廣告互動和錯誤資料，具體範圍及可選控制以官方隱私政策和 SDK 配置為準。廣告服務提供方發生變化時會重新提示確認，確認前不初始化廣告。

在您選擇“同意並進入遊戲”後，遊戲初始化廣告 SDK，用於底部橫幅展示及您主動選擇的激勵影片復活。穿山甲/GroMore SDK 會透過其程式碼直接採集、處理裝置標識 Android ID，以及裝置品牌與型號、系統和 API 版本、語言、時區、螢幕引數、CPU 與儲存狀態、IP 地址、網路型別與狀態、運營商、應用包名和版本、前後臺狀態、廣告展示/點選/轉化及錯誤、效能、反作弊相關資訊，用於廣告載入、效果統計、歸因、安全和服務穩定性。SDK 的具體處理範圍受版本、裝置和隱私配置影響，詳見第三節。關閉橫幅僅隱藏當前頁面的橫幅，切換到其他遊戲頁面後會重新請求展示；這不等於撤回全部廣告服務授權。

當前廣告整合透過 SDK 隱私控制介面限制個性化推薦，並限制定位、電話狀態、應用列表、OAID、Wi-Fi 資訊及外部儲存寫入等可控採集能力。Android ID 不屬於已完全關閉的採集項：廣告 SDK 會在您同意後處理 Android ID，用於廣告展示、效果統計與歸因、反作弊；其隱私介面用於限制採集頻率，不代表完全禁止讀取。遊戲業務程式碼不自行讀取 Android ID，也不向廣告 SDK 主動提供自定義裝置標識。這些限制不等於廣告無需聯網或完全不處理裝置資訊。廣告素材如使用感測器互動，SDK 可能按其版本和裝置能力處理加速度、陀螺儀等感測器資訊。

3. 測試診斷

啟用廣告除錯日誌的測試版本會在裝置本地記錄廣告載入、關閉、獎勵校驗、錯誤碼及 SDK 版本等事件，用於定位異常；日誌檔案達到約 256 KB 後重新記錄。應用不自動將該本地日誌傳送給我們。若您主動反饋問題，可以選擇提供必要的截圖、裝置資訊或日誌，請先遮蓋無關個人資訊。

4. 聯絡我們

當您向我們諮詢或提出個人資訊請求時，我們會處理您主動提供的聯絡方式、請求內容和必要材料，用於回覆、核實請求及處理問題。請勿傳送密碼、完整證件照片或與問題無關的敏感資訊；確需核驗時，我們將說明理由並儘量減少所需資訊。

5. 友盟統計

首次啟動且尚未同意隱私政策時，廣告與統計服務均不初始化。您點選“同意並進入遊戲”後，廣告與友盟統計一併開啟，並初始化友盟移動統計 SDK，用於分析新增與活躍使用者、留存、使用時長，以及主線、首領、每日、無盡模式的遊玩與引導情況。處理範圍包含裝置標識資訊（Android ID、OAID、GUID、GAID，實際取決於裝置與 SDK 能力）、裝置型號與系統版本、應用版本、IP 地址及網路狀態、啟動與前後臺使用記錄；玩法事件包含模式、關卡或波次、首領難度、遊玩秒數、分數、所在幕、剩餘磚塊、失敗次數、退出或重試選擇、復活流程結果、球群峰值、首次分身與形成球群的耗時、分身連鎖、道具接住和漏接數量，以及引導步驟完成或跳過。資料用於發現難度、節奏、道具及復活體驗問題，不附帶姓名、電話、郵箱、精確觸控軌跡或完整存檔；遊戲本地按局彙總，不逐幀上傳。未啟用統計時不快取或補報這些自定義事件，自動測試與各模式測試入口均不計入玩法分析。0.44.7 起，普通版本升級沿用已有的同意記錄，不僅因版本更新重複彈窗；尚未同意、已撤回或清除應用資料後，會再次展示提示。當前版本不提供單獨的統計開關。同意記錄儲存後，後續啟動自動開啟相應服務；影片復活仍需您主動選擇，不會自動播放。

友盟移動統計使用 common 10.0.1 與 asms 1.8.7.2 基礎元件，不接入推送、分享、解除安裝分析或高階運營分析元件；關閉應用列表、Wi-Fi MAC 和安裝來源採集介面，不申請定位、電話狀態或外部儲存許可權。廣告 SDK 對識別符號的限制僅針對廣告服務，不表示友盟統計不處理裝置標識。

五、儲存、刪除與安全

遊戲進度和設定儲存在裝置的應用私有空間，通常持續至您清除應用資料或解除安裝。清除資料會刪除本地存檔，當前版本不能透過雲端恢復。廣告及統計 SDK 處理的資訊由其提供方按照相應政策的儲存地點、期限和安全措施管理，您可以透過本頁連結瞭解詳情或聯絡其提供方行使權利。

您傳送給我們的諮詢材料僅在處理請求及依法需要的期限內保留，目的實現後刪除或匿名化。我們採用必要的訪問控制、最小化處理等措施保護資訊；任何系統都無法保證絕對安全，如發生影響您權益的資訊保安事件，我們會依法採取補救及通知措施。

六、您的選擇與權利

  • 拒絕或撤回：首次啟動等需要確認時的隱私提示中選擇“不同意並退出”，遊戲將退出，不初始化廣告和統計。已經同意後，可在首頁設定的“廣告與隱私”中再次閱讀政策，選擇“不同意並退出”撤回授權、停止後續廣告請求與遊戲統計事件、呼叫統計 SDK 停止介面並退出遊戲。下次啟動重新展示提示。撤回不會自動刪除此前已經處理的資訊；涉及第三方持有的資訊，可透過其政策列出的渠道提出請求，我們會協助處理。
  • 查詢、更正、複製或刪除：您可以聯絡我們提出個人資訊請求。我們會核實必要資訊並依法處理，或說明無法處理的原因；涉及廣告服務方獨立持有的資訊，我們會提供其聯絡路徑並協助您提出請求。
  • 本地資料刪除：可以在 Android 系統設定中清除本遊戲應用資料或解除安裝。操作前請確認是否需要保留本地遊戲進度。
  • 賬號登出：當前版本沒有本遊戲賬號註冊功能，因此沒有對應賬號登出流程。透過第三方平臺使用的賬號，應在該平臺辦理。

如對處理結果有異議，您可以依法向有關主管部門投訴、尋求救濟。

七、未成年人保護

未成年人應在監護人的指導下閱讀和使用本遊戲。涉及不滿十四周歲兒童個人資訊時，我們將依法取得監護人同意並採取相應保護措施；監護人可以就相關資訊的查詢、更正或刪除聯絡我們。請監護人合理安排未成年人的遊戲時間，並指導其謹慎使用廣告和外部連結。

當前版本不在遊戲內主動收集姓名、身份證號碼或人臉資訊。本政策不表示遊戲已接入任何平臺的實名認證或防沉迷服務；後續如引入相關處理，將另行說明處理主體、資訊型別和用途，並依法履行必要程式。

八、隱私政策網頁

本頁面透過 GitHub Pages 託管，不設定評論、表單、廣告、統計指令碼或主動追蹤 Cookie。訪問網頁會向託管服務傳送正常網路請求，GitHub 可能處理訪問 IP、瀏覽器及請求日誌等資訊，託管基礎設施可能位於境外。我們不向本網頁上傳您的遊戲存檔或廣告日誌。詳情請參閱GitHub 隱私宣告。
