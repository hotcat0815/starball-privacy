1. 運営主体と適用範囲

『Pixel Pinball: Star Island Journey』（以下、「本ゲーム」といいます）は、北京洋友創祥技術有限公司（以下「当社」といいます）が運営しております。本ポリシーは、本ゲームのAndroidアプリおよび本プライバシーポリシー表示ページに適用されます。現在の Android パッケージ名はcom.yycx.starball。

使用前にこのポリシー、特にサードパーティの広告サービスと未成年者保護のセクションをお読みください。サードパーティのプラットフォーム、外部 Web ページ、および個別にインストールするアプリケーションには、独自に提供するサービスに適用される独自のプライバシー ポリシーが適用されるものとします。このポリシーは第三者のポリシーに代わるものではなく、また当社が個人情報保護の責任を免除できることを意味するものでもありません。

2. 情報の処理方法

1. ローカルゲームデータ

プレイ体験を保存するために、ゲームはレベルのロック解除、クリア記録、スコア、スター評価、チャレンジ記録、外観の選択、ガイダンスの完了ステータス、サウンドとアニメーションの設定、プライバシー ポリシーの認定バージョン、およびその他のデータをアプリケーションのプライベート ストレージ領域に保存します。現在のバージョンには独自のアカウントやクラウド アーカイブ サーバーがありません。プライバシー ポリシーに同意した後は、以下に説明するメイン レベルのイベントは、Umeng を通じて報告され、完全なアーカイブはアップロードされません。

2. 広告サービス

[同意してゲームに参加する] を選択すると、ゲームは下部バナーの表示と、アクティブに選択したインセンティブ ビデオの復活のために広告 SDK を初期化します。 Pangolin/GroMore SDK は、コードを通じてデバイス識別 Android ID、デバイスのブランドとモデル、システムと API のバージョン、言語、タイムゾーン、画面パラメータ、CPU とストレージのステータス、IP アドレス、ネットワークの種類とステータス、オペレータ、アプリケーションのパッケージ名とバージョン、フロントとバックのステータス、広告の表示/クリック/コンバージョンとエラー、パフォーマンス、広告読み込みに関する不正行為対策関連情報、パフォーマンス統計、帰属、セキュリティとサービスの安定性を直接収集して処理します。 SDK の特定の処理範囲は、バージョン、デバイス、プライバシー設定によって影響されます。詳細についてはセクション 3 を参照してください。バナーを閉じると、現在のページのバナーが非表示になるだけで、他のゲーム ページに切り替えた後に表示が再要求されます。これは、すべての広告サービスの認可を取り消すことを意味するものではありません。

現在の広告統合では、SDK プライバシー制御インターフェイスを介したパーソナライズされた推奨事項が制限され、位置、電話ステータス、アプリケーション リスト、OAID、Wi-Fi 情報、外部ストレージへの書き込みなどの制御可能な収集機能が制限されます。 Android ID は、完全にオフになっているコレクション アイテムではありません。広告 SDK は、広告表示、パフォーマンス統計とアトリビューション、不正行為防止についてお客様の同意後に Android ID を処理します。プライバシー インターフェイスは収集の頻度を制限するために使用されますが、これは読み取りが完全に禁止されることを意味するものではありません。ゲーム ビジネス コードは Android ID 自体を読み取りません。また、カスタム デバイス ID を広告 SDK に積極的に提供することもありません。これらの制限は、広告にインターネット接続が必要ないことや、デバイス情報がまったく処理されないことを意味するものではありません。クリエイティブでセンサー インタラクションを使用する場合、SDK はバージョンとデバイスの機能に応じて、加速度、ジャイロスコープなどのセンサー情報を処理する場合があります。

3. テスト診断

広告のデバッグ ログを有効にするテスト バージョンでは、異常を特定するために、広告の読み込み、終了、報酬検証、エラー コード、SDK バージョンなどのイベントがデバイス上でローカルに記録されます。ログ ファイルは約 256 KB に達すると再記録されます。アプリケーションはこのローカル ログを自動的に送信しません。率先して問題を報告する場合は、必要なスクリーンショット、デバイス情報、またはログを提供することを選択できます。関係のない個人情報はまず隠蔽してください。

5. ウメンの統計

プライバシーポリシーに同意されていない初回起動時は、広告・統計サービスともに初期化されません。 「同意してゲームに参加する」をクリックすると、広告とUmeng Statisticsが一緒に開き、Umeng Mobile Statistics SDKが初期化され、新規ユーザーとアクティブユーザー、維持率、使用時間、メインライン、ボス、デイリー、エンドレスモードのゲームプレイとガイダンスが分析されます。処理範囲には、デバイス識別情報 (Android ID、OAID、GUID、GAID、実際の状況はデバイスと SDK の機能によって異なります)、デバイスのモデルとシステムのバージョン、アプリケーションのバージョン、IP アドレスとネットワークのステータス、起動、フロントエンドとバックエンドの使用記録が含まれます。ゲームプレイ イベントには、モード、レベルまたはウェーブ、ボスの難易度、プレイ秒数、スコア、シーン、残りのレンガ、失敗の数、終了または再試行のオプション、復活プロセスの結果、ボール グループのピーク、最初のアバターとボール グループを形成するのにかかった時間、アバター チェーン、キャッチまたはミスしたプロップの数、完了またはスキップされたガイダンス ステップが含まれます。データは、難易度、リズム、小道具、復活体験などの問題を発見するために使用されます。名前、電話番号、電子メール、正確なタッチ トラック、完全なアーカイブは付属しません。ゲームはゲームごとにローカルに集約され、フレームごとにアップロードされません。統計が有効になっていない場合、これらのカスタム イベントはキャッシュまたはレポートされず、自動テストと各モードのテスト入口はゲームプレイ分析に含まれません。 0.44.7 以降、通常のバージョンアップでは既存の同意レコードが使用されます。バージョンアップによりポップアップが繰り返し表示されるだけでなく、同意が得られなかった場合、同意が撤回された場合、またはアプリケーションデータが消去された場合にも、再度プロンプトが表示されます。現在のバージョンでは、個別の統計スイッチは提供されていません。レコードの保存に同意すると、その後の起動時に対応するサービスが自動的に開きます。ビデオの復活にはアクティブな選択が必要であり、自動的には再生されません。

Umeng Mobile Statistics は、共通の 10.0.1 および asms 1.8.7.2 の基本コンポーネントを使用します。プッシュ、共有、アンインストール分析、または高度な運用分析コンポーネントにはアクセスしません。これにより、アプリケーション リスト、Wi-Fi MAC、およびインストール ソース収集インターフェイスが閉じられ、測位、電話ステータス、または外部ストレージのアクセス許可は適用されません。広告 SDK の識別子に対する制限は、広告サービスのみを対象としたものであり、Umeng Statistics がデバイス識別子を処理しないことを意味するものではありません。

4. デバイス許可の説明

  • ネットワーク アクセスとネットワーク ステータス:は、有効化を選択した後、広告の読み込み、統計レポート、ネットワーク判断、およびポリシー Web ページを開くために使用されます。
