一、运营主体与适用范围

《像素弹球：星岛奇旅》（以下简称“本游戏”）由北京悠游创想科技有限公司（以下简称“我们”）运营。本政策适用于本游戏 Android 应用及本隐私政策展示页面。当前 Android 包名为 com.yycx.starball。

请在使用前阅读本政策，尤其是第三方广告服务和未成年人保护部分。第三方平台、外部网页及您另行安装的应用，其独立提供的服务适用各自的隐私政策。本政策不能替代第三方政策，也不意味着我们可以免除自身的个人信息保护责任。

二、我们如何处理信息

1. 本地游戏数据

为保存您的游玩体验，游戏在应用私有存储空间保存关卡解锁、通关记录、分数、星级、挑战记录、外观选择、引导完成状态、声音及动效设置、隐私政策授权版本等数据。当前版本没有自行搭建账号或云存档服务器；您同意隐私政策后，会通过友盟上报下文说明的主线关卡事件，不上传完整存档。

2. 广告服务

本版本通过 GroMore 聚合穿山甲和腾讯广告，提供横幅、自愿观看的激励视频及关卡间插屏。腾讯广告 SDK 在用户同意后按调度参与广告加载与展示，处理 OAID、设备与系统信息、应用及网络信息、广告交互和错误数据，具体范围及可选控制以官方隐私政策和 SDK 配置为准。广告服务提供方发生变化时会重新提示确认，确认前不初始化广告。

在您选择“同意并进入游戏”后，游戏初始化广告 SDK，用于底部横幅展示及您主动选择的激励视频复活。穿山甲/GroMore SDK 会通过其代码直接采集、处理设备标识 Android ID，以及设备品牌与型号、系统和 API 版本、语言、时区、屏幕参数、CPU 与存储状态、IP 地址、网络类型与状态、运营商、应用包名和版本、前后台状态、广告展示/点击/转化及错误、性能、反作弊相关信息，用于广告加载、效果统计、归因、安全和服务稳定性。SDK 的具体处理范围受版本、设备和隐私配置影响，详见第三节。关闭横幅仅隐藏当前页面的横幅，切换到其他游戏页面后会重新请求展示；这不等于撤回全部广告服务授权。

当前广告集成通过 SDK 隐私控制接口限制个性化推荐，并限制定位、电话状态、应用列表、OAID、Wi-Fi 信息及外部存储写入等可控采集能力。Android ID 不属于已完全关闭的采集项：广告 SDK 会在您同意后处理 Android ID，用于广告展示、效果统计与归因、反作弊；其隐私接口用于限制采集频率，不代表完全禁止读取。游戏业务代码不自行读取 Android ID，也不向广告 SDK 主动提供自定义设备标识。这些限制不等于广告无需联网或完全不处理设备信息。广告素材如使用传感器交互，SDK 可能按其版本和设备能力处理加速度、陀螺仪等传感器信息。

3. 测试诊断

启用广告调试日志的测试版本会在设备本地记录广告加载、关闭、奖励校验、错误码及 SDK 版本等事件，用于定位异常；日志文件达到约 256 KB 后重新记录。应用不自动将该本地日志发送给我们。若您主动反馈问题，可以选择提供必要的截图、设备信息或日志，请先遮盖无关个人信息。

4. 联系我们

当您向我们咨询或提出个人信息请求时，我们会处理您主动提供的联系方式、请求内容和必要材料，用于回复、核实请求及处理问题。请勿发送密码、完整证件照片或与问题无关的敏感信息；确需核验时，我们将说明理由并尽量减少所需信息。

5. 友盟统计

首次启动且尚未同意隐私政策时，广告与统计服务均不初始化。您点击“同意并进入游戏”后，广告与友盟统计一并开启，并初始化友盟移动统计 SDK，用于分析新增与活跃用户、留存、使用时长，以及主线、首领、每日、无尽模式的游玩与引导情况。处理范围包含设备标识信息（Android ID、OAID、GUID、GAID，实际取决于设备与 SDK 能力）、设备型号与系统版本、应用版本、IP 地址及网络状态、启动与前后台使用记录；玩法事件包含模式、关卡或波次、首领难度、游玩秒数、分数、所在幕、剩余砖块、失败次数、退出或重试选择、复活流程结果、球群峰值、首次分身与形成球群的耗时、分身连锁、道具接住和漏接数量，以及引导步骤完成或跳过。数据用于发现难度、节奏、道具及复活体验问题，不附带姓名、电话、邮箱、精确触控轨迹或完整存档；游戏本地按局汇总，不逐帧上传。未启用统计时不缓存或补报这些自定义事件，自动测试与各模式测试入口均不计入玩法分析。0.44.7 起，普通版本升级沿用已有的同意记录，不仅因版本更新重复弹窗；尚未同意、已撤回或清除应用数据后，会再次展示提示。当前版本不提供单独的统计开关。同意记录保存后，后续启动自动开启相应服务；视频复活仍需您主动选择，不会自动播放。

友盟移动统计使用 common 10.0.1 与 asms 1.8.7.2 基础组件，不接入推送、分享、卸载分析或高级运营分析组件；关闭应用列表、Wi-Fi MAC 和安装来源采集接口，不申请定位、电话状态或外部存储权限。广告 SDK 对标识符的限制仅针对广告服务，不表示友盟统计不处理设备标识。

五、保存、删除与安全

游戏进度和设置保存在设备的应用私有空间，通常持续至您清除应用数据或卸载。清除数据会删除本地存档，当前版本不能通过云端恢复。广告及统计 SDK 处理的信息由其提供方按照相应政策的存储地点、期限和安全措施管理，您可以通过本页链接了解详情或联系其提供方行使权利。

您发送给我们的咨询材料仅在处理请求及依法需要的期限内保留，目的实现后删除或匿名化。我们采用必要的访问控制、最小化处理等措施保护信息；任何系统都无法保证绝对安全，如发生影响您权益的信息安全事件，我们会依法采取补救及通知措施。

六、您的选择与权利

  • 拒绝或撤回：首次启动等需要确认时的隐私提示中选择“不同意并退出”，游戏将退出，不初始化广告和统计。已经同意后，可在首页设置的“广告与隐私”中再次阅读政策，选择“不同意并退出”撤回授权、停止后续广告请求与游戏统计事件、调用统计 SDK 停止接口并退出游戏。下次启动重新展示提示。撤回不会自动删除此前已经处理的信息；涉及第三方持有的信息，可通过其政策列出的渠道提出请求，我们会协助处理。
  • 查询、更正、复制或删除：您可以联系我们提出个人信息请求。我们会核实必要信息并依法处理，或说明无法处理的原因；涉及广告服务方独立持有的信息，我们会提供其联系路径并协助您提出请求。
  • 本地数据删除：可以在 Android 系统设置中清除本游戏应用数据或卸载。操作前请确认是否需要保留本地游戏进度。
  • 账号注销：当前版本没有本游戏账号注册功能，因此没有对应账号注销流程。通过第三方平台使用的账号，应在该平台办理。

如对处理结果有异议，您可以依法向有关主管部门投诉、寻求救济。

七、未成年人保护

未成年人应在监护人的指导下阅读和使用本游戏。涉及不满十四周岁儿童个人信息时，我们将依法取得监护人同意并采取相应保护措施；监护人可以就相关信息的查询、更正或删除联系我们。请监护人合理安排未成年人的游戏时间，并指导其谨慎使用广告和外部链接。

当前版本不在游戏内主动收集姓名、身份证号码或人脸信息。本政策不表示游戏已接入任何平台的实名认证或防沉迷服务；后续如引入相关处理，将另行说明处理主体、信息类型和用途，并依法履行必要程序。
